## How to Use This Repo

Suggested flow (works for both exams and overall revision):

1. Go week-wise using **Instructor Lectures**: [`sir_lectures/`](./sir_lectures)
2. Reinforce concepts using **handwritten class/tutorial notes**: [`class_notes/`](./class_notes)
3. Do faster revision using **weekly notes**: [`weekly_notes/`](./weekly_notes)
4. Before exams, switch to:

   * **revision notes**: [`revision_notes/`](./revision_notes)
   * **past papers**: [`past_exams/`](./past_exams)
   * **final exam pack**: [`final_exam/`](./final_exam)

## Final Exam Survival Checklist (After Week 8)

Final exam focus is primarily **after Week 8**. Use this as a quick checklist to structure revision:

* **Week 8 — Design Rules**

  * Rules, principles, and design guidance for better interfaces
  * Key material: `sir_lectures/week_08_-_Design_rules/`

* **Week 9 — Experimental Setups**

  * Designing experiments and evaluation setups
  * Key material: `sir_lectures/week_09_-_Experimental_Setups/`

* **Week 10 — Measuring Usability**

  * Usability metrics, usability testing approaches, and evaluation methods
  * Key material: `sir_lectures/week_10_-_Measuring_Usability/`

* **Week 11 — Designing for iOS and Apple HIG**

  * Mobile UI design practices and platform-specific guidelines
  * Key material: `sir_lectures/week_11_-_Designing_for_iOS_and_Apple_HIG/`

* **Week 12 — Emotional Interaction**

  * Emotion-aware interaction and designing for emotional impact
  * Key material: `sir_lectures/week_12_-_Emotional_Interaction/`

* **Week 13 — AR, MR, and VR**

  * Extended reality concepts and interaction considerations in AR/MR/VR
  * Key material: `sir_lectures/week_13_-_AR,_MR,_and_VR/`

Recommended practice order:

1. Review Weeks 8–13 lectures
2. Revise using `weekly_notes/` and `revision_notes/` for Weeks 8–13
3. Solve `final_exam/` practice sets
4. Attempt `past_exams/` under time constraints
